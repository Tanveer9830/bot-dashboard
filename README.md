# Dashboard Preview (Vercel-ready)

This is a **visual preview only** — fake sample data, no real login, not
connected to your actual Discord bot yet. It exists so you can see a real,
live URL for the dashboard design before the real backend/OAuth work happens.

## Deploy to Vercel

1. Push this folder to a GitHub repo (or a subfolder of your bot repo).
2. Go to vercel.com → New Project → Import your GitHub repo.
3. Vercel auto-detects Vite — leave all settings as default.
4. Click Deploy. You'll get a live URL like `your-project.vercel.app`.

No environment variables are needed for this preview.
